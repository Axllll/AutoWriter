# AutoWriter

**A simple automatic typing application built with Python and PySide6.**

AutoWriter allows you to paste text, choose a delay, and automatically type it into another application as if you were typing it yourself.

## Features

- Automatic text typing.
- Customizable delay before typing starts.
- Simple and clean graphical interface.
- Built with Python and PySide6.

## Download

Download the latest version from the GitHub Releases page:

[Download AutoWriter](https://github.com/Axllll/AutoWriter/releases/latest)

Download `AutoWriter.exe` and run it on Windows.

## Requirements

If you want to run the source code, install Python and the required dependencies:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python main.py
```

## Technologies

- Python
- PySide6
- PySide6-Fluent-Widgets
- PyAutoGUI

## How to use

1. Open AutoWriter.
2. Paste the text you want to type.
3. Set the delay in seconds.
4. Click **Start Writing**.
5. Switch to the application where you want the text to appear.
